A beat tracker is implemented based on the work of Ellis
[1], which combines a step of tempo induction with
a dynamic programming algorithm. The solution is designed
to work on the [Ballroom dataset](https://mtg.upf.edu/ismir2004/contest/tempoContest/node5.html), and therefore was
adjusted using a train subset and tested in a test subset of
the same dataset. In addition, a basic downbeat detector is
proposed and tested.

## References
[1] D. P. Ellis, “Beat tracking by dynamic programming,”
Journal of New Music Research, vol. 36, no. 1, pp. 51–
60, 2007.
